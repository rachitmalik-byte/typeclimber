# 🏔️ TypeClimber - Modern Typing Mountain Racer & Arcade

**TypeClimber** is a modern, high-adrenaline typing game and spiritual successor to the classic game *Cliffhanger*. Race against AI climbers up dangerous mountain peaks by typing complex text passages with speed, accuracy, and rhythm.

## 🚀 Features

- **5 Game Modes**:
  - 🏔️ **Campaign Mode**: 7 progressive mountain peaks (*Green Hills*, *Rocky Cliffs*, *Snow Mountain*, *Ice Peak*, *Volcano*, *Storm Peak*, *Mount Everest*).
  - ⚡ **Free Play**: Infinite vertical altitude climbing.
  - ☄️ **Boulder Dodge (Arcade)**: Single action word rockfall mode.
  - ⏱️ **Time Attack & Speed Sprint**: 30s & 60s high-speed WPM rush modes.
  - 🧘 **Zen Practice**: Pressure-free relaxing passage practice.
- **First-Keystroke Race Trigger**: Race timer and AI opponent stay paused until your very first keystroke.
- **HTML5 Canvas 2D Parallax Engine**: 60 FPS multi-layer mountain silhouettes, cliff textures, climber movement animations, speed aura trails, and dynamic weather (blizzards, rockfalls, lava embers, lightning).
- **Web Audio Sound Synthesizer**: Procedural mechanical keyboard switch profiles (*Cherry MX Blue*, *Brown*, *Red*, *Topre thock*), error crunch sounds, combo chimes, and ambient mountain soundscapes.
- **Performance Analytics Dashboard**: Live WPM progression charts, accuracy distribution, match history log, and **Weakest Key Heatmap Diagnostics**.
- **Climber Locker & Cosmetics**: Unlock and equip custom skins, ropes, trail auras, and victory flags using earned Climb Coins.

## 🛠️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/rachitmalik-byte/typeclimber.git
   cd typeclimber
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. Open your browser at `http://localhost:8085` (or `http://localhost:8086`).
